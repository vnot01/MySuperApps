# Tenants Apps Documentation

## Overview
This folder contains technical documentation for **Tenant Management Applications** - Mobile apps and Web dashboards for RVM operators, administrators, and business owners.

## Target Users
- **RVM Operators** - Daily operations and maintenance
- **Business Owners** - Revenue and performance monitoring
- **System Administrators** - System management and configuration
- **Maintenance Teams** - Device maintenance and troubleshooting

## Architecture
- **Web Dashboard** - Laravel-based web application (part of MyRVM-Platform)
- **Mobile Apps** - iOS and Android for field operations
- **Admin Panel** - Advanced management interface
- **Reporting System** - Analytics and business intelligence
