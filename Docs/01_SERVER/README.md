# Server Documentation (MyRVM-Platform)

## Overview
This folder contains technical documentation for the **MyRVM-Platform** backend system, which serves as the central server for the RVM ecosystem.

## Architecture
- **Laravel Framework** - Backend API and web application
- **PostgreSQL** - Primary database
- **Redis** - Caching and session management
- **Docker** - Containerized deployment
- **WebSocket** - Real-time communication
